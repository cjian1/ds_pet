ds_pet · 便携版说明 / Portable version
======================================

ds_pet 基于开源项目 dsh-pet（PC2005-cloud，MIT）二次创作：
https://github.com/PC2005-cloud/dsh-pet
ds_pet is a remix of the open-source project dsh-pet by PC2005-cloud (MIT).

项目主页 / Project page: https://github.com/cjian1/ds_pet


【中文】
这是免安装的便携版：把整个 ds_pet 文件夹放到你想放的地方（比如「文档」里），
双击里面的 ds_pet.exe 就能打开。想要开始菜单图标、一键更新，请改用安装版
（ds_pet-<版本>-win-x64-setup.exe）。

第一次打开被 Windows 拦住？这个应用没有付费购买代码签名证书，Windows 会提示
「Windows 已保护你的电脑」。点「更多信息」→「仍要运行」就行，之后不会再问。

打开后：她会出现在桌面右下角，任务栏右下角多一个小鲸鱼图标（找不到就点「^」展开）。
第一次会弹出设置窗口，选一家 AI 服务（默认 DeepSeek，也支持 OpenAI、Claude、Gemini、
Kimi、智谱、通义、Ollama 本地模型等）、填上 API Key 就能聊天；不填也能拖她、甩她、点播动作。
Ctrl+Alt+P 随时显示 / 隐藏她。设置和聊天记录保存在 %APPDATA%\ds_pet。

卸载：右键她 →「退出 ds_pet」，再删掉这个文件夹；想连数据一起删，再删除 %APPDATA%\ds_pet。


【English】
This is the portable version: put the whole ds_pet folder wherever you like (for example
in Documents) and double-click ds_pet.exe inside it. For a Start menu entry and one-click
updates, use the installer instead (ds_pet-<version>-win-x64-setup.exe).

Blocked the first time? The app isn't signed with a paid code-signing certificate, so
Windows shows "Windows protected your PC". Click "More info" → "Run anyway"; it won't ask again.

After that she appears in the bottom-right corner of your desktop and a little whale shows
up in the taskbar corner (click ^ if it's tucked away). The first time, Settings opens so you
can pick an AI provider (DeepSeek by default; OpenAI, Claude, Gemini, Kimi, Qwen, local
Ollama models and more are supported) and add an API key to chat with her. Without a key
you can still drag her, fling her and play her animations.
Press Ctrl+Alt+P to show / hide her anytime. Settings and chat history live in %APPDATA%\ds_pet.

To remove it: right-click her → "Quit ds_pet", then delete this folder. To delete your data
too, also delete %APPDATA%\ds_pet.
